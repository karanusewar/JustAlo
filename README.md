# JustAlo - Intercity Bus & Fleet Booking Transit Platform

JUSTALO is a comprehensive transit ecosystem featuring a Flutter mobile & web app, Node.js backend server, and React/TypeScript franchisee & super-admin governance platform.

## 📱 Mobile App (Flutter)
Located in `justalo_app/`
- Bus Booking & Seat Map Selection
- Parcel Express Delivery
- Rent Fleet / Tempo Traveller / Luxury Bus Rental
- Live Vehicle Tracking & E-Tickets
- Firebase Phone OTP & Google Authentication

## 💻 Codebase Governance Suite (React / TypeScript)
Located in `justalo_complete_codebase/`
- Super Admin Global Governance Console
- Franchisee P&L and Route Telematics Dashboard

## ⚙️ Backend API
Located in `backend/`
- Node.js / Express server

## 🚀 Automatic Android APK Building
This repository is configured with **GitHub Actions**. Every push to `main` automatically compiles `app-release.apk`!
- Go to the **Actions** tab on GitHub.
- Click on the latest workflow run.
- Download `app-release.apk` under **Artifacts**.
