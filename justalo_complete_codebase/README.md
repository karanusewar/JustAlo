# JUSTALO Transit - Multi-Hub Franchisee & Super Admin Console
Production-grade transit governance & corridor management platform.

## Features
- Super Admin Master Governance: Fleet limits, commission overrides, emergency broadcast SOS, compliance audit.
- Franchisee Scoped Operations: P&L per-diem yields, bus dispatches, tour & charter fleets.
- Interactive Google Maps Transit Telematics: AIS-140 GPS real-time bus pings, NH-46 & NH-52 corridors, Indore ISBT hub.
- Full Flutter / Dart Architecture: BLoC pattern, models, screens ready for Android & iOS.
- Typography: Plus Jakarta Sans with crisp modern UI styling.

## Quickstart (Web)
```bash
npm install
npm run dev
```
App runs locally at: http://localhost:3000

## Quickstart (Flutter Mobile)
```bash
cd flutter_transit_app
flutter pub get
flutter run
```
